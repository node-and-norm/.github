# Node & Norm visual identity

Use the stacked name for square profiles and the horizontal wordmark in wider spaces. The iris ampersand joins the two words. [Website identity guide and color palette](https://nodeandnorm.org/visual-identity)

| Asset | Where to use it |
| :--- | :--- |
| [Stacked name, PNG](current/logo.png) · [SVG](current/logo.svg) | The 400 × 400 carbon square carries the full name at avatar size. Use the PNG for the GitHub organization picture. |
| [Horizontal wordmark for light backgrounds](current/wordmark-light.svg) · [for dark backgrounds](current/wordmark-dark.svg) | The same outlined lettering used in the website footer and header. Choose the file for the surface it will sit on. |
| [Organization banner, PNG](current/banner.png) | The GitHub README banner carries the name, “Independent research on human control in AI,” and the large iris ampersand. |
| [Banner for a stacked logo, PNG](current/banner-stacked.png) | Use where a company avatar overlaps the left edge of the cover. The line of text sits beside the ampersand on the right. |

Both banners retain the supplied 4200 × 700 PNG artwork. The [SVG banner](current/banner.svg) embeds the same PNG as the GitHub banner so existing image links continue to work. The [current manifest](current/manifest.json) records the source and SHA-256 checksum of each artwork file.

Earlier identity exports and their [original manifest](manifest.json) remain here for historical references. The [Space Grotesk license](current/SPACE-GROTESK-LICENSE.txt) covers the typeface. The program name and marks are separate from the licenses for individual research projects.
