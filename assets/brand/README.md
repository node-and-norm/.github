# Node & Norm identity

The current identity matches [nodeandnorm.org](https://nodeandnorm.org/): carbon `#191820`, paper `#f7f7f4`, iris `#b5afff`, and citron `#d7f59a`.

| Current asset | Use |
| :--- | :--- |
| [current/logo.png](current/logo.png) | 400 × 400 organization avatar: the iris Witness mark on carbon |
| [current/logo.svg](current/logo.svg) | Vector version of the same square logo |
| [current/banner.png](current/banner.png) | Approved 4200 × 700 banner: Counterfile, Amend, Bearing, Register, then the node&norm wordmark |
| [current/banner.svg](current/banner.svg) | Vector banner with outlined lettering, preserving the site's exact glyphs without a font dependency |
| [current/manifest.json](current/manifest.json) | SHA-256 hashes and provenance for current assets |

The banner omits Witness because the organization avatar already carries that mark. Preserve the order, proportions, and clear space. Its left margin allows for the overlapping LinkedIn company logo. GitHub displays the banner inside the organization profile README.

The wordmark uses the website's Space Grotesk glyphs: weight 500 for the letters, weight 400 for the iris ampersand, and the site's proportional spacing. The font's [SIL Open Font License](current/SPACE-GROTESK-LICENSE.txt) is included. The banner is static identity artwork and represents no research result.

Files outside `current/`, including `manifest.json`, the earlier ZIP, and the earlier artwork notes, preserve the September 18 Midnight / Electric blue identity for existing links and provenance. They are superseded for new use. The current asset manifest is separate from that historical import manifest.

The font license does not grant rights to the Node & Norm name or marks. Each research repository states its own license.
