# Node & Norm organization profile

This repository maintains the [public GitHub directory](https://github.com/node-and-norm) for Node & Norm’s independent research on human control in AI. The [website](https://nodeandnorm.org/) carries the essays. GitHub provides the methods, software and records readers can use to examine the findings.
